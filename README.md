# DiscoveredMaterials — Grand Challenge 05 submission

**Predicting heat transport across solid interfaces**: a two-tier framework
from atomic structure to thermal boundary conductance G(T) and resistance
R_K(T) = 1/G(T), with no per-specimen fitting.

* **Fast tier:** the full-dispersion Landauer model on MACE-OMAT-0 phonons,
  taking seconds per interface.
* **Accurate tier:** an atomistic Green's function with MACE force constants of
  the actual interface, ~1 CPU-hour.

At a glance (all numbers regenerated by `tbc/make_report.py`; details and
every caveat in `tbc/README.md`):

* **Li 2022 Al/Si G(T), 82–705 K:** 3.6% (fit set); room temperature 395 vs
  381 MW m⁻² K⁻¹; the >400 K rise 0.31 vs 0.43 MW m⁻² K⁻² (~70%).
* **Never fitted (but used as no-regression guards in model selection):**
  * Al/GaN 5.7%, 436 vs 425 at 300 K, slope 0.28 vs 0.39;
  * epitaxial Al/sapphire (Cheng 2020, 80–479 K) 5.8%.
* **Strongest baseline:** full-dispersion DMM on the same phonons with the same
  electron–phonon term scores 18 / 13 / 14% on these three sets.
* **Sandell** metal/PMMA stacks 13%; **Chang** TiC ratio 1.44 vs 1.48 (with
  stated assumptions).
* **Honest exceptions:**
  * on Al/sapphire the Debye AMM with the same e-ph term scores 4.6% (this
    model 5.8%);
  * on Li's second Al/Si specimen (310 at 300 K, 19% below specimen 1) this
    model is 25% off, full-dispersion DMM + e-ph 12%.
* **Atomistic ground truth (MACE-AGF, 14 coherent pairs):** two-class specular
  efficiency, leave-one-out 14% (10 pairs) and 29% (4 heterovalent III-V/IV
  pairs).
  * First-round blind tests (single η of the time): 31%, with the two III-V/IV
    pairs failing (+54%, +104%). That led to the two-class η.
  * A fresh, pre-registered blind round tests it on five new pairs: **5% mean
    deviation** (−4, +7, +12, −3, −1%), against 42% for full-dispersion DMM.
